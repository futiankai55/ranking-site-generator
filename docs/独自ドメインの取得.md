# 独自ドメインの取得〜Netlify接続 手順

## 1. ドメインを取得する（年間約1,000〜2,000円）
おすすめのドメイン登録サービス：

サービス	特徴	.com目安
お名前.com	国内最大手・日本語サポート	約1,500円/年
Xserver Domain	Xserverと連携しやすい	約1,480円/年
Cloudflare Registrar	仕入れ値でドメイン提供・管理画面が英語	約1,100円/年
Namecheap	海外・安価	約1,200円/年
おすすめドメイン名の例：

ai-tools-ranking.jp
ai-tools-hikaku.com
aitools-ranking.net
AdSense審査では .com .net .jp いずれも問題ありません。

## 2. NetlifyにカスタムドメインをNS設定で接続する
ドメイン取得後、以下の手順で接続します：

① Netlifyの管理画面で設定

https://app.netlify.com にアクセス
サイト gregarious-smakager-bbd6ab を選択
Domain management → Add a domain
取得したドメイン名を入力して追加
② ドメイン登録サービス側でネームサーバー変更

Netlifyが表示する4つのネームサーバー（例: dns1.p01.nsone.net）を、お名前.comなどのネームサーバー設定欄に貼り付けて保存します。

③ 反映を待つ（数分〜最大48時間）

Netlifyが自動でSSL証明書（HTTPS）も発行してくれます。

## 3. サイトのbaseURLを更新してデプロイ
ドメインが確定したら、Hugo設定を更新する必要があります。例えば ai-tools-ranking.jp を取得した場合：


# hugo.toml の baseURL を変更してから再デプロイ
cd output/portal
netlify deploy --dir public --prod
どのドメイン登録サービスを使うか決まったら、取得したドメイン名を教えてもらえれば接続手順をサポートします。
