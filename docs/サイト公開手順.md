# ランキングサイト公開手順

Claude Codeスキルで記事を生成し、Hugo + Netlify + 独自ドメインで公開するまでの手順をまとめます。

---

## 前提条件

- Claude Code がインストールされている
- Node.js / npm が利用可能
- Python 仮想環境（`.venv`）がセットアップ済み

---

## Step 1: Hugo をインストール

```bash
HUGO_VERSION="0.147.9"
cd /tmp
curl -L "https://github.com/gohugoio/hugo/releases/download/v${HUGO_VERSION}/hugo_extended_${HUGO_VERSION}_linux-amd64.tar.gz" -o hugo.tar.gz
tar xzf hugo.tar.gz hugo
mv hugo ~/.local/bin/
hugo version
```

---

## Step 2: 記事を生成する

Claude Code のスキルで記事を生成します（APIキー不要）。

```
/generate-article --site ai-tools --type all
```

生成される記事（計7本）:
- ランキング記事 × 1（5,000〜8,000字）
- 個別紹介記事 × 5（各3,000〜5,000字）
- FAQ記事 × 1（2,000〜3,000字）

出力先: `output/ai-tools/content/`（生成ステージング場所。ポータル本体とは別ディレクトリ）

---

## Step 3: SEO後処理・DB記録

```bash
# 構造化データ（JSON-LD）・内部リンクを記事に付加
source .venv/bin/activate
python -m src.cli.main seo --site ai-tools

# 生成記事をSQLiteに記録（重複防止）
python -m src.cli.main record --site ai-tools --scan output/ai-tools/content/

# ポータル（output/portal/）へ取り込む
python -m src.cli.main sync-portal --site ai-tools
```

---

## Step 4: Hugo サイトをセットアップ

`kenjatimejp.com` の実体はポータル用ディレクトリ `output/portal/` です（`ai-tools` などの各テーマは `sync-portal` で取り込まれる側であり、Hugoプロジェクト自体はここに置きません）。

```bash
mkdir -p output/portal
cd output/portal

# Hugo サイトを初期化
hugo new site . --force

# テーマ（PaperMod）をインストール
git init
git submodule add https://github.com/adityatelange/hugo-PaperMod themes/PaperMod
```

`hugo.toml` を編集（後述の独自ドメイン取得後に `baseURL` を更新）:

```toml
baseURL = "https://kenjatimejp.com/"
languageCode = "ja"
title = "AIツールランキング"
theme = "PaperMod"
```

---

## Step 5: Hugo サイトをビルド

```bash
cd output/portal
hugo
```

ビルド成功すると `public/` ディレクトリに静的ファイルが生成されます。

---

## Step 6: Netlify CLI をインストール・デプロイ

```bash
# Netlify CLI をインストール
npm install -g netlify-cli

# ログイン（ブラウザで認証）
netlify login

# 本番デプロイ
cd output/portal
netlify deploy --dir public --prod
```

初回デプロイ時にNetlifyのプロジェクトが自動作成されます。  
デプロイ完了後に表示される `Production URL` でサイトにアクセスできます。

---

## Step 7: 独自ドメインを取得・接続

### 7-1. ドメインを取得

お名前.com・Xserver・Namecheap などでドメインを取得（例: `kenjatimejp.com`）。  
年間費用: 約1,000〜2,000円。

### 7-2. Netlify にドメインを追加

1. https://app.netlify.com → 対象サイト → **Domain management** → **Add a domain**
2. 取得したドメイン名を入力して追加
3. Netlifyが表示するネームサーバー4つをメモ（例: `dns1.p01.nsone.net` など）

### 7-3. ドメイン登録サービス側でネームサーバーを変更

**Xserverの場合:**
1. Xserverアカウント（ドメイン管理画面）にログイン
2. 対象ドメイン → **ネームサーバー設定**
3. 「他のネームサーバーを利用する」を選択
4. Netlifyのネームサーバー4つを入力して保存

反映まで数分〜最大48時間かかります。Netlifyが自動でHTTPS証明書を発行します。

### 7-4. baseURL を更新して再デプロイ

```bash
# hugo.toml の baseURL を独自ドメインに変更後
cd output/portal
hugo && netlify deploy --dir public --prod
```

---

## Step 8: Google Search Console に登録

1. https://search.google.com/search-console にアクセス
2. **「ドメイン」**でプロパティを追加: `kenjatimejp.com`
3. 表示された TXTレコードをXserver（DNS設定）に追加して所有権確認
4. **サイトマップを送信**: `https://kenjatimejp.com/sitemap.xml`
5. **URL検査** → トップページや主要記事を「インデックス登録をリクエスト」

---

## Step 9: Bing Webmaster Tools に登録

Yahoo! JAPANの検索にも反映されます（BingのインデックスをYahoo!が使用）。

1. https://www.bing.com/webmasters にアクセス
2. Microsoftアカウントでログイン
3. サイトURLを追加
4. Google Search Consoleのインポート機能で設定を自動コピー
5. サイトマップを送信: `https://kenjatimejp.com/sitemap.xml`
