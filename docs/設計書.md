# Google AdSense収益化 ランキングサイト自動生成システム 設計書

## Context

人間がテーマを指定するだけで、ランキングサイト（○○ランキング・おすすめ10選・比較・まとめ）を自動生成・SEO最適化まで一気通貫で完結させるシステム。Google AdSense収益化を前提とし、将来的に1000サイト規模まで拡張可能な構成とする。

**今回の成果物**: 設計書（本ファイル）＋ CLAUDE.md の作成のみ。実装はユーザー確認後に着手。

**前提条件の確認結果**:
- WordPress環境は未準備のため、**静的サイト生成（Hugo）を第一候補**とし、WordPress連携はオプション対応とする
- アイキャッチ画像自動生成はPhase2以降（Phase1はプレースホルダー画像で対応）
- まず設計書とCLAUDE.mdを完成させ、実装フェーズは別途着手

```sql
CREATE TABLE sites (
    id          TEXT PRIMARY KEY,        -- 'ai-tools'
    name        TEXT NOT NULL,           -- 'AIツールランキング'
    theme       TEXT NOT NULL,
    wp_url      TEXT NOT NULL,
    wp_user     TEXT NOT NULL,
    wp_app_pass TEXT NOT NULL,           -- 暗号化保存
    status      TEXT DEFAULT 'active',
    created_at  DATETIME DEFAULT CURRENT_TIMESTAMP
);

-- 記事管理
CREATE TABLE articles (
    id              INTEGER PRIMARY KEY AUTOINCREMENT,
    site_id         TEXT REFERENCES sites(id),
    wp_post_id      INTEGER,             -- WordPress側のID
    article_type    TEXT NOT NULL,       -- 'ranking'|'individual'|'faq'|'top'|'related'
    title           TEXT NOT NULL,
    slug            TEXT NOT NULL,
    target_keyword  TEXT,
    status          TEXT DEFAULT 'draft',-- 'draft'|'published'|'failed'
    content_hash    TEXT,                -- 重複チェック用SHA256
    generated_at    DATETIME,
    published_at    DATETIME,
    UNIQUE(site_id, slug)
);

-- ランキング対象アイテム
CREATE TABLE ranking_items (
    id          INTEGER PRIMARY KEY AUTOINCREMENT,
    site_id     TEXT REFERENCES sites(id),
    name        TEXT NOT NULL,
    rank        INTEGER,
    score       REAL,
    description TEXT,
    url         TEXT,
    pros        TEXT,                    -- JSON配列
    cons        TEXT,                    -- JSON配列
    created_at  DATETIME DEFAULT CURRENT_TIMESTAMP
);

-- 内部リンクマップ
CREATE TABLE internal_links (
    id          INTEGER PRIMARY KEY AUTOINCREMENT,
    site_id     TEXT REFERENCES sites(id),
    from_slug   TEXT NOT NULL,
    to_slug     TEXT NOT NULL,
    anchor_text TEXT NOT NULL
);

-- 生成ジョブ (Phase2+)
CREATE TABLE generation_jobs (
    id          INTEGER PRIMARY KEY AUTOINCREMENT,
    site_id     TEXT REFERENCES sites(id),
    job_type    TEXT NOT NULL,
    status      TEXT DEFAULT 'pending',
    payload     TEXT,                    -- JSON
    error       TEXT,
    created_at  DATETIME DEFAULT CURRENT_TIMESTAMP,
    completed_at DATETIME
);
```

### 生成パイプライン

```
1. ConfigLoader     → YAMLを読み込み・バリデーション
2. KeywordPlanner   → メインKW・LSIキーワード展開
3. OutlineGenerator → 各記事のアウトライン生成 (Claude API)
4. ContentGenerator → アウトラインをもとに本文生成 (Claude API)
5. SEOProcessor     → 構造化データ・内部リンク・メタ情報付加
6. DuplicateChecker → content_hashで重複検出
7. WordPressPublisher→ 画像生成→記事投稿→カテゴリ・タグ設定
8. SitemapUpdater   → sitemap.xml更新・ping送信
```

### 記事タイプ別仕様

| 記事タイプ | 文字数目安 | 主な構成要素 |
|---|---|---|
| トップページ | 3,000字 | サイト概要・人気記事リンク・カテゴリ一覧 |
| ランキング記事 | 5,000〜8,000字 | 選定基準・比較表・各順位解説・FAQ |
| 個別紹介記事 | 3,000〜5,000字 | 概要・機能・料金・メリデメ・使い方・評価 |

### 方式A: 静的サイト生成（Hugo） ← Phase1推奨

WordPressサーバー不要。GitHub Pages / Cloudflare Pages に無料ホスティング可能。


**Google AdSense設置**: Hugo テンプレートの `<head>` と記事本文内に AdSense コードを挿入するだけ。

### 方式B: WordPress連携（Phase2以降・オプション）

WordPress Application Passwords（WordPress 5.6+標準機能）を使用。

| 操作 | エンドポイント | メソッド |
|---|---|---|
| 記事投稿 | `/wp-json/wp/v2/posts` | POST |
| カテゴリ作成 | `/wp-json/wp/v2/categories` | POST |
| タグ作成 | `/wp-json/wp/v2/tags` | POST |
| 画像アップロード | `/wp-json/wp/v2/media` | POST |
| 記事更新 | `/wp-json/wp/v2/posts/{id}` | PUT |

設定YAMLに `publisher: hugo` または `publisher: wordpress` を指定するだけで切り替え可能な設計とする。

## 5. AI記事生成エンジン

### Claude API設定

```python
# src/utils/claude_client.py
import anthropic

client = anthropic.Anthropic()  # ANTHROPIC_API_KEY を環境変数から読み込み

def generate_article(prompt: str, system: str) -> str:
    message = client.messages.create(
        model="claude-sonnet-4-6",         # 高品質生成
        max_tokens=8192,
        system=system,
        messages=[{"role": "user", "content": prompt}]
    )
    return message.content[0].text
```

### E-E-A-T対応プロンプト設計

**システムプロンプト（全記事共通）**

```
あなたは{theme}分野で5年以上の実務経験を持つ専門家ライターです。
以下のガイドラインを厳守してください：

【Experience】実際に使用した経験に基づく具体的な感想・数値を含める
【Expertise】専門用語を正確に使いつつ、初心者にも分かりやすく説明する
【Authoritativeness】公式サイト・信頼できる一次情報源を根拠として明示する
【Trustworthiness】メリットだけでなくデメリット・注意点も正直に記載する

禁止事項：
- 不確かな情報の断定（「〜です」→「〜とされています」「〜と報告されています」）
- 他サイトからのコピー・類似表現
- 根拠のない最上級表現（「最高の」「唯一の」等）
```

### 重複回避・独自性向上

1. **content_hash チェック**: 生成済み記事のSHA256ハッシュをDBに保存し、類似度が閾値以上なら再生成
2. **キーワード多様化**: 同テーマでも切り口を変える（「初心者向け」「コスパ重視」「機能比較」等）
3. **独自調査セクション追加**: 「編集部が実際に試した結果」セクションをテンプレートに組み込む
4. **LSIキーワード活用**: メインKW以外の関連語を自然に本文へ散りばめる

### ハルシネーション低減

1. **ファクトグラウンディング**: 価格・機能は公式URLを設定YAMLに記載し、プロンプトに注入
2. **不確実性の明示**: 「執筆時点の情報」「最新情報は公式サイトを確認」を定型文として挿入
3. **Two-pass生成**: 1回目でアウトライン生成 → レビュー → 2回目で本文生成
4. **数値の検証指示**: 「価格・数値は必ず[DATA]として提供する情報のみ使用し、それ以外は記載しない」

## 6. スケーラビリティ設計

### Phase1→Phase3 の移行パス

| 規模 | DB | 実行 | 画像 | 公開方式 | インフラ |
|---|---|---|---|---|---|

## CLAUDE.md（作成内容）

```markdown
# Ranking Site Generator

Google AdSense収益化を目的とした、ランキングサイト自動生成システム。

## 開発コマンド
- 記事生成(dry-run): `python -m src.cli.main generate --site <site_id> --dry-run`
- 記事生成(投稿): `python -m src.cli.main generate --site <site_id> --publish`
- レポート: `python -m src.cli.main report --site <site_id>`
- テスト: `pytest tests/`

## 環境変数 (.env)
- ANTHROPIC_API_KEY: Claude API キー
- WP_ENCRYPTION_KEY: WordPress認証情報の暗号化キー

## 設定ファイル
- config/sites/*.yaml: サイトごとの設定
```
