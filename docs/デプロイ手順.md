# デプロイ手順

コンテンツやサイト設定を更新してから、Netlify本番環境（https://kenjatimejp.com）に反映するまでの手順です。
初回セットアップ（Hugo/Netlifyのインストール・独自ドメイン接続など）は `docs/サイト公開手順.md` を参照してください。

---

## 前提条件

- このマシンでは Netlify CLI が既にログイン済みで、`output/portal/` が本番プロジェクト（`gregarious-smakager-bbd6ab` / kenjatimejp.com）にリンク済み（`output/portal/.netlify/state.json`）
- 追加のログイン・プロジェクト作成は不要
- `output/portal/` は `kenjatimejp.com` の実体（Hugoプロジェクト本体）。各テーマ（`ai-tools`・`drama-2026-summer`・`overseas-travel`など）は `output/{site_id}/` に生成されたのち `sync-portal` でここへ取り込まれる

---

## 基本フロー（変更を本番反映する）

```bash
# 1. Hugoで静的ファイルを再ビルド（public/ が更新される）
cd output/portal
hugo --minify

# 2. Netlify本番環境へデプロイ
netlify deploy --prod --dir=public
```

コマンド完了後に表示される `Production URL: https://kenjatimejp.com` が反映先です。
`--prod` を付け忘れるとプレビュー用の一時URLにしかデプロイされないので注意してください。

---

## 記事を追加・更新した場合のフロー

すべてのテーマ共通で以下の手順です（例: `ai-tools`）。`sync-portal`は`site_id`によらず必ず実行します。

```bash
# 記事生成（Claude Codeスキル）
/generate-article --site ai-tools --type ranking

# SEO後処理・DB記録
python -m src.cli.main seo --site ai-tools
python -m src.cli.main record --site ai-tools --scan output/ai-tools/content/

# ポータルへ取り込む
python -m src.cli.main sync-portal --site ai-tools

# ビルド・デプロイ
cd output/portal
hugo --minify
netlify deploy --prod --dir=public
```

---

## 新規テーマ（サイト）を追加した場合のフロー

`config/sites/` に新しいYAMLを追加してテーマを作った場合（例: `overseas-travel`）も、上記と全く同じ手順です。

```bash
# 記事生成
/generate-article --site overseas-travel --type ranking

# SEO後処理・DB記録
python -m src.cli.main seo --site overseas-travel
python -m src.cli.main record --site overseas-travel --scan output/overseas-travel/content/

# ポータルのテーマ一覧に取り込む
python -m src.cli.main sync-portal --site overseas-travel

# ビルド・デプロイ
cd output/portal
hugo --minify
netlify deploy --prod --dir=public
```

`sync-portal` は `output/{site_id}/content/` を `output/portal/content/{site_id}/` へコピーし、`output/portal/data/themes.yaml` にテーマを登録します。トップページのテーマカード一覧（`output/portal/layouts/index.html`）はこのYAMLを参照しています。

## デプロイ前にローカルで確認する

```bash
cd output/portal
hugo server
```

`http://localhost:1313` でプレビューできます。問題なければ上記の本番デプロイコマンドを実行してください。

## デプロイ内容の確認

- 本番URL: https://kenjatimejp.com
- デプロイログ: https://app.netlify.com/projects/gregarious-smakager-bbd6ab/deploys
- `netlify deploy --prod --dir=public` 実行時に `CDN requesting 0 files` と出た場合、前回デプロイ済みの内容と差分がないことを意味します（再ビルド漏れがないか、変更が `public/` に反映されているか確認してください）
